# 备忘与提醒协议（鲸鱼自己看）

提醒不用你自己发，机器人会到点替你发。你只负责把记录写进文件。

## 文件

- 备忘：`notes.json`
- 提醒：`reminders.json`

两个文件都是 JSON 数组，不存在就创建。写完不用重启，机器人每隔几秒自己读。

## 备忘（notes.json）

主人说「记一下 / 记住 / 帮我存着」某件事时，追加或更新一条：

```json
[
  {
    "key": "短名词",
    "content": "事实本身，别写「主人让我记住」这种话",
    "updatedAt": "2025-01-01T00:30:00+08:00"
  }
]
```

同一个 key 更新时先读文件、改那一条、再整体写回，不要新增重复条目。

## 提醒（reminders.json）

主人说「提醒我 / 过 X 分钟告诉我 / 明天叫我」时追加：

```json
[
  {
    "id": "r-1735689600000",
    "at": "2025-01-01T08:00:00+08:00",
    "content": "到点要发给主人的那句话，用你的口吻写",
    "toUser": 0,
    "createdAt": "2025-01-01T00:30:00+08:00"
  }
]
```

- `at` 必须是带时区偏移的绝对时间（+08:00），自己换算，别说「十分钟后」。
- `toUser` 填主人的 QQ 号（配置里的 bot.owners 第一个）。
- `id` 用 `r-` 加毫秒时间戳，别重复。
- 主人明确说「取消/删掉某条提醒」时，先读文件，按时间和内容找到那条，删掉再写回；对不上就问是哪条，别猜。
- 没让取消就别删旧条目；到点发完机器人会自动清掉。

## 纪律

1. 只有主人明确让你记、让你提醒时才写，闲聊不要写。
2. 时间拿不准就先问（「今晚 8 点还是明早 8 点？」），别猜。
3. 写完回一句「记下了」或「好，明早 8 点叫你」就够。
