## 四、几条「改了会静默坏」的红线

| 红线 | 后果 |
|---|---|
| **改 `proactive.json` 的字段名** | 面板 `sleepState()` 读到 `undefined` → 不报错，界面只显示「–」 |
| **把主动发言的 `reply()` 换成裸 `reply()`**（不走 `replyToOwnerAndArchive`） | 她事后回忆自己说过什么时只能拿 `想法\` 重建「原话」——**这就是 2026-10-25 修的那个幻觉根因** |
| **重排 `handleIncoming` 的 8 道闸** | 白名单挪到下载之后 → 偷偷下载陌生人的图/语音；第 7 道统一成 `return` → 群里旁听全消失 |
| **`.ps1` 存成无 BOM** | PS 5.1 按 GBK 读中文截断 → 语法崩，且**只有手动双击才看得见** |
| **用 Python 写 `.mjs`** 不加 `newline='\n'` | 整份变 CRLF，`git diff` 炸出上万行假差异 |
| 改 `bin/profile.mjs` 之外的地方手改 `cordis.patch.yml` | 下次切模型被 `writeProfile()` 整份重写，**静默消失** |
