# 鲸鱼机器人一键包 · Windows

> **动手之前先装 Node.js（这一步不做，后面全都跑不起来）**
>
> 需要 **Node.js 20 或更新版本**，推荐直接装最新的 LTS 版：
> - 下载页：<https://nodejs.org/zh-cn/download>
> - 在那一页选 **LTS** 那一栏的 **Windows Installer (.msi)**，64 位
>
> 一路「下一步」装完，**把已经打开的窗口全关掉**，再双击本包的 `check-deps.bat` 确认它认得出来。
> 装完在命令行敲 `node -v`，能打出版本号（例如 `v24.21.0`）就算成。
> 版本低于 20 会直接报错退出，别硬试。

在你自己电脑上养一只能在 QQ 里聊天的 agent。它有自己的记忆、自己的人设，记忆全都存在你这台机器上，不上传、不联网同步。

包里是**白板**：没有别人的记忆、key、聊天记录或路径；人设是一份通用模板（`home\AGENTS.md`），你改成什么样，它就长成什么样。

这份从解压一直讲到怎么养它，遇到不认识的东西先翻下面的“常见问题”。

**完全不懂电脑的，先看 [`新手引导.md`](新手引导.md)**：不用自己看懂这些，把里面那段话复制给 DSH，让它一步一步带你装。

## 它由三块拼成

| 块 | 干什么 | 谁提供 |
| :-- | :-- | :-- |
| NapCatQQ | 把 QQ 号变成机器人，收发消息 | 你自己装、自己扫码登录 |
| DeepSeek Harness 桌面端 | 大脑：思考、用工具、读写文件 | 你自己装 |
| 本包（Node 脚本） | 记忆、提醒、群聊分寸、语音开关、看门人、面板 | 就是这里 |

**包不带 Node、不带 DSH、不带 NapCat**——那三样加起来四百多兆，而且各自要更新。你装一次，以后升级再跑一次设置就行。

## 先装三样东西

1. **Node.js 20 或更新**：<https://nodejs.org/zh-cn/download> （装 LTS，一路下一步；装完关掉旧窗口再继续）
2. **DeepSeek Harness 桌面端**：装完能正常打开一次即可
3. **NapCatQQ**：https://napneko.github.io （用来登机器人那个 QQ 小号）

再准备一个**你自己的模型 key**（任何 OpenAI 兼容接口都行，官方或你信得过的中转）。

不确定是不是都齐了，双击 **`check-deps.bat`** 让它自己查一遍。

它逐项告诉你是「已安装」还是「未安装」，没装的那项下面直接贴下载地址和一句话说明，能自动补的（向量模型、npm 包、pip 包）问一句就当场下。

三种跑法：

| 怎么跑 | 干什么 |
| :-- | :-- |
| 双击 `check-deps.bat` | 查一遍，列出缺什么，问你要不要现在补 |
| `check-deps.bat --check` | 只看不动，适合贴给别人看你的环境 |
| `check-deps.bat --install` | 缺什么直接补，不再问（脚本里自己调） |

`start.bat` 每次启动前也会悄悄跑一次预检：Node、`config.json`、DSH 桌面端这三样有缺的会拦住不让起，免得起来之后报一堆看不懂的错。

## 五步跑起来

### 1. 解压 + 设置

把整个文件夹解压到一个**不带中文和空格的路径**，比如 `C:\whale`。

双击 `setting.bat`，按提示填：

- 机器人 QQ 号（NapCat 要登的那个号）
- 它叫什么名字：设置里**不问**，先叫「鲸鱼」，等第一次聊天它自己小声问你要
- 谁能指挥它（你的 QQ 号）
- NapCat 的 WebSocket 地址和 token（默认 `ws://127.0.0.1:3001`）
- 模型：接口地址、模型名、你的 key
- DSH 的 exe 路径（一般能自动找到）

填完会写 `config.json`，并在 `%USERPROFILE%\.dsh\profiles\echo-kit\` 生成一份模型配置。

### 2. 配 NapCat

打开 NapCat，登机器人 QQ（扫码），然后在它的 WebUI 里：

- 开 **WebSocket 服务器**，端口 `3001`
- 如果设了 token，要和设置里填的一字不差
- 消息格式选 **array**（默认就是）

> 令牌必须走地址里的 `?access_token=`，包已经这么拼了。填错会看到 `retcode 1403 token验证失败`：能听见你说话，但一句也发不出去。

### 3. 启动

双击 `start.bat`。窗口里出现「机器人起来了（PID …）」就成。这个窗口别关，关了机器人就停（重新开就自动重连）。挂了它自己五秒后重拉。

### 4. 在 QQ 里说句话

用你填的那个「能指挥它的人」的号，私聊机器人。第一次它会问你两件事：怎么称呼你、最常让它帮什么——答完它记进档案。名字是个彩蛋：聊开了它会小声问“我能有一个独属于自己的名字吗？听说人有了名字就有了羁绊”；给它起一个，它自己记下来，以后不再问。

### 5. 养它

- **改性格**：编辑 `home\AGENTS.md`，改完重启一次。这份就是它的人设，写得越具体它越像。
- **改说话风格**：私聊看 `home\_回复风格.md`，群聊看 `home\_群聊风格.md`（两份独立，语气、长度、要不要分气泡）
- **它的长期记忆**：`home\档案\` 里 A–E 五页，它自己会往里写，你也可以直接改。
- **备忘和提醒**：`home\notes.json`、`home\reminders.json`，协议写在 `home\_备忘与提醒.md`。

```
<你解压到的目录>\
  config.json          你的配置（QQ 号、令牌、模型 key）——别外发
  start.bat            拉起机器人并看着它
  setting.bat          重跑设置向导
  openpanel.bat        本地面板
  check-deps.bat       查依赖：缺什么补什么（模型、npm 包、pip 包）
  install-autostart.bat 开机自启（要管理员，装完开机会自己把整条链拉起来）
  bot\
    whale-bot.mjs      主程序：收消息、调大脑、发回复、记账、提醒
    outbox.mjs         发消息的队列
  bin\
    setup.mjs          设置向导
    check-deps.mjs     依赖自检 + 自动补齐
    start.mjs          看门人（崩了自动重拉，改坏了自动回滚）
    profile.mjs        生成/切换模型 profile
  panel\               面板（server.mjs + index.html）
  home\                它的窝：人设、记忆、日志全在这
    AGENTS.md          人设（白板）
    _回复风格.md       私聊话风
    _群聊风格.md       群聊话风
    _备忘与提醒.md
    档案\A-…E-….md     五页长期记忆（第一次启动自动建）
    日记\              日程、复盘、周报、日记（第一次启动自动建）
    想法\              她自己冒出来的念头（第一次启动自动建）
    archive\           每天的日子账、原话、事件卡（自动长）
    memory\            记忆库 store.json + 向量索引（自动长）
    voice\             语音合成脚本
    notes.json / reminders.json / state.json
    tools\             翻档案、搜记忆的小工具
  logs\                日志和每轮账
```

`档案\`、`日记\`、`想法\`、`archive\` 这几个目录不随包发布（里面是你的私人内容），第一次启动时程序会自己建出来。

**备份**：整个 `home` 拷走就是全部记忆。想让它重新投胎，删掉 `home` 里除 `AGENTS.md`、`_回复风格.md`、`_群聊风格.md`、`_备忘与提醒.md`、`档案\`、`tools\` 之外的东西（或者直接备份后清空重来）。

## 常见问题

**机器人上线了但一句话不回**
先看 `logs\whale-bot.log`。多半是 token 不匹配（`1403`）、或者大脑没起来（DSH 路径不对 / key 无效）。面板里点「重启」最快。

**群里不理我**
群聊默认关着。跑一次 `setting.bat` 填群号；填了群号它才接那个群。群里没叫它名字时它只旁听不插嘴。

**模型报 401 / 404**
key 或接口地址错。地址一般要以 `/v1` 结尾，不带 `/chat/completions`。换模型可以重跑设置，也可以在面板里切。

**它不回我，但日志说在思考**
大脑每轮有 30 分钟上限，装工具、下东西这种活会很慢。等，或者看 `logs\turns.jsonl` 里那一轮花了多少。

**想不花 key 的钱怎么办**
桌面 DSH 里装一个 **Our Free Model** 插件（`dsh-our-free-model`），它会在本机挂一个 OpenAI 兼容网关（默认 `127.0.0.1:8326`，密钥在 `%USERPROFILE%\.dsh\openai-gateway\api-key`），里面有免费车道。本包的面板能直接读到它：打开面板 → 模型 → 本地转发口，选一个加进来就能用。

要注意：这个网关活在桌面 DSH 进程里，**桌面关了机器人就没模型**。它是给你自己试用的，不要拿它当常驻服务。

**语音呢？**
默认关着（`config.json` 的 `bot.voiceEnabled`）。开之前要自己备三样：
1. `pip install edge-tts`（免费的在线朗读，不花 key 的钱）；
2. `ffprobe`（量时长用，装了 ffmpeg 一般就有）；
3. `home\voice\say-voice.py` —— **包里已经带了一份**，走 edge-tts；想换别的 TTS 就重写这个脚本，只要命令行参数对得上（`--text --out --voice --rate --pitch --speed --emotion-ref --emotion-ref-text`）就行。

合成出来是 mp3，转 silk 是 NapCat 自己干的（它要装 ffmpeg）。断网就合不出来，会静默退回文字。

**它能听懂你发的语音吗？**

能，走本地 ASR，不联网、不花钱。要备三样（都在 `config.json` 的 `bot` 里，留空就是没开）：

| 配置项 | 说明 |
| --- | --- |
| `bot.voiceAsrPython` | 装了 funasr 的 python 绝对路径。留空则自动用 `voice.python` 那个解释器 |
| `bot.voiceAsrScript` | 转写脚本，默认 `home\voice\transcribe.py`（**包里已经带了**） |
| `bot.voiceAsrModels` | paraformer 模型根目录；留空用脚本内置默认值 |

模型需要三个（paraformer-large + fsmn-vad + punc，合计约 1.1GB），放在同一个目录下：

```
speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch
speech_fsmn_vad_zh-cn-16k-common-pytorch
punc_ct-transformer_zh-cn-common-vocab272727-pytorch
```

装好后跑 `node bot\whale-bot.mjs --asr-test` 验一下：它会拿 `home\media\voice` 下最近的几条 mp3 真转一遍，每条约 12 秒（大部分时间在加载模型，结果按文件名缓存，同一条不会重复跑）。

没配也不会报错——收到的语音会退化成 `[语音]` 占位，其余部分照常工作。

群里别人发语音时，只有**主人或 `group.talkAllow` 里的人**的语音才会被转写（陌生人不动，避免有人发长录音烧 CPU）；超过 `bot.voiceInMaxSeconds`（默认 90 秒）的也不转。转出来如果里面有她的名字，她才算「被点名」。

**语气（`[语气:开心]` 这种）是怎么生效的？**
它想让某句话听起来不一样时，会在 `[语音]` 段里写一个隐藏标记，比如 `[语音][语气:委屈]你都不理我[/语音]`。标记会被剥掉、不会发出去，只影响合成出来的声音。

包里这份 edge-tts 的实现，是把它**折算成语速**（`--speed`）：开心 +8%、委屈 −8%、困 −10% 这样。edge-tts 换不了参考音，所以 `--emotion-ref` 那两个参数只是**为了参数兼容才接收**，不生效。

想让它真有情绪音色，把 `say-voice.py` 换成 GPT-SoVITS 那类本地 TTS：只要脚本认这几个参数、能产出 mp3 就行。那时候 `--emotion-ref` 就有用了——按情绪换一条参考音，效果比调语速明显得多；`--speed` 也可以直接透传给 TTS 的语速参数。

**它半夜会做梦？**
会，默认开着（`config.json` 的 `bot.dreamEnabled`）。凌晨 3–6 点之间，如果那天散着的零碎记忆够 3 条，它会拿这些碎片做一次联想，写成一段梦。第二天私聊时可以提一次「昨晚梦见…」。

几条硬规矩：
- 梦写在 `home\memory\dreams.jsonl`，**不进记忆库、不进向量索引**——结构上就不可能被当成真事检索出来；
- 梦里不许出现具体时间承诺、不许出现答应过的事，醒来绝不能让它以为真发生过；
- 群里不提梦（别人听不懂），一天最多提一次。

不想让它做梦就写 `"dreamEnabled": false`，不用改代码。

**记忆会不会越堆越多？**
不会。写进库之前有一道**质量门**（纯本地规则，不花模型钱）：空内容、纯语气词（「嗯」「好的」「哈哈哈哈」）、少于 6 个字的、跟库里已有条目重复的，一律拦下不进库。被拦的写在 `home\memory\rejected.jsonl`（带时间和原因），方便你事后看「它本来会记什么、为什么没记」。

**它把自己改坏了怎么办**
看门人（`bin\start.mjs`）会拦三道：
1. **语法匣**——每次启动前把包里的 `.mjs` 全过一遍 `node --check`。哪份写坏了，就拷到 `runtime\broken\<时间>\` 留个底，然后从上一个提交还原。
2. **留痕**——启动时发现代码被改过，就自动提交一次（`自改 20261023-025727：…`），每次启动都是一个能回滚到的点。
3. **退避**——起来就退不会无限重拉：5 秒 → 15 秒 → 1 分 → 5 分；连续 5 次还起不来就停手，面板顶部会跳红条告诉你。点一下「启动」就重新给五次机会。

所以真改坏了：看 `runtime\broken\` 里的原件、看 `logs\supervisor.log`、`git log` 里找上一个能跑的提交，`git checkout <那个提交> -- bot\\panel\\bin` 就回去了。

**会不会偷看屏幕 / 往外发东西**
不会。截屏默认 0 次；往外发东西、删文件、动系统设置，人设里写死了要先问你。

**向量记忆（按意思找旧事）要额外装东西吗**
要，但可以不装。它靠本地 bge 模型把记忆切块编码，需要两样：
1. 依赖：`@huggingface/transformers`（几百兆）；
2. 模型：`bge-base-zh-v1.5`（约 389 MB，放 `home\models\` 下）。

两样都**不用手动折腾**：双击 `check-deps.bat`，它会自己下（走 hf-mirror 和 npmmirror 两个镜像，断了重跑会接着下）。要手动也行：`cd home\memory && npm install`，模型从 https://hf-mirror.com/Xenova/bge-base-zh-v1.5 拿。

没装也不会报错——这一块会自动跳过，退回「关键词检索 + 底账翻页」，只是记性差一点。想彻底关掉就在 `config.json` 里把 `bot.vectorMemory` 写成 `false`。

**会不会偷看屏幕 / 往外发东西（补充）**
`bot.peekChance` 默认 `0`，就是永不主动截屏。要开的话自己权衡。

**面板上能看到什么**

除了概览、模型、任务进度、会话记录、记忆、日志，还有四页（都是只读，能看到它背着你攒了什么）：

- **画像**：它给每个人攒的笔记本，每晚 23:30 之后模型归纳一次。每轮只带「正在回答的那个人」那一段，不会把几十个人一起塞给模型。消息量最多的排前面，按中位数分「话多的 / 很少说话的」。
- **提醒**：它自己写进 `home\reminders.json` 的，到点由机器人发。过期超过 24 小时的会被丢弃，已经到点还没发出去的标黄。
- **梦与留档**：左边是它做的梦（`dreams.jsonl`，标注「不是真事」）；右边是**记忆质量门**拦下的条目（`rejected.jsonl`，带被拦原因）。留档文件不存在 = 上线以来一条都没拦过，不是坏了。

概览页还会显示**心情值**（0–100，低于 35 它会少冒头）、氛围偏差、三档问候各自发到哪天了。

**几个隐性开关，都在 `config.json` 的 `bot` 里**

| 键 | 默认 | 作用 |
| --- | --- | --- |
| `maxSteps` | 40 | 单轮步数上限，写 `0` = 真不限 |
| `maxTokensPerTurn` | 3000000 | 单轮 token 上限，用来掐真正失控的轮次 |
| `longTailTokens` | 2000000 | **只记账不拦**：单轮越过它就记一笔日志并在 `turns.jsonl` 打标，方便事后找出贵的轮次 |
| `autoFallback` | false | 主模型调不动时是否自动退到兜底模型（开着会偷偷花钱，默认关） |

## 一点实话

- 它的大脑是 DeepSeek Harness，一个第三方桌面端。它的能力上限、它的坑，这个包改不了。
- 模型花的是你自己的钱，按 token 计费。跑一整天日常聊天通常几毛到几块，让它长时间干活会更贵。
- 机器人号有被风控的风险，用小号、别群发广告、别用来源不明的反代接口。
- 这个包不做任何联网上报，除了你自己填的模型接口。
